# Breakout-Deluxe

HTML5 Canvas と JavaScript（Vanilla JS）で作成したブロックくずしゲームです。
スコア・レベル・コンボの表示、ライフ制（ハート表示）などを実装し、遊びやすさを意識して開発しました。

## Demo
▶️ https://rinakido.github.io/Breakout-Deluxe/

## 主な機能
- スコア／レベル／コンボのリアルタイム表示
- ライフ制（ハート表示）によるゲームオーバー判定
- 段ごとに色分けされたブロック配置
- レスポンシブ対応（ブラウザ上でクリック／タップ操作に対応）

## 使用技術
- HTML5 / CSS3
- JavaScript（Vanilla JS）

## ファイル構成
- `index.html`：ゲーム画面の構造
- `style.css`：デザイン・レイアウト
- `script.js`：ゲームロジック（当たり判定、スコア計算、レベル管理など）

## ローカルでの実行方法
1. このリポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開くだけで起動します
